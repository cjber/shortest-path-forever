### Changed

- The farming tour now drives Shortest Path only through its public API, so a gathering addon can do the same.

### For addon authors

- **Walking routes, stop observers and journey state in API 2.6.** `NavigateRoute(owner, stops, options)` takes `options.policy`, `"normal"` (the default) or `"walking"`, which keeps every leg a walk along the walking map; bad options answer `nil, "invalid"`. `ObserveStops(owner, callback)` calls `callback(phase, index, stop, state)` for that owner's running route, inside the planner's own step, with phase `"arrived"` or `"settled"`. `JourneyState()` reads whether the journey is busy, pending, settling, failed or blocked by combat or a corpse run, and every leg's mode, measured walk and walk error.
